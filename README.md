# Regional Sales Analytics

An end-to-end Business Intelligence project that transforms raw sales data into actionable insights using SQL Server, ETL, Data Warehousing, and Power BI.

> **Project Status:** 🚧 Under Development

## Overview

This project demonstrates the complete Business Intelligence workflow:

- Raw Sales Dataset (Excel/CSV)
- SQL Server Staging Database
- Data Mart Design (Star Schema)
- ETL using SQL Scripts
- Power BI Dashboard
- Business Insights & KPI Reporting

## Technology Stack

- SQL Server
- SQL (T-SQL)
- SSMS
- Power BI
- DAX
- Microsoft Excel
